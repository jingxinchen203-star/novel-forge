# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through a public GitHub issue. Use GitHub's private vulnerability reporting feature for this repository when available. If that feature is unavailable, contact the repository owner through the GitHub profile and include a concise description, affected component, reproduction steps, and potential impact.

Please do not include API keys, OAuth secrets, database credentials, session cookies, or personal data in reports.

## Scope

Security reports are most useful for authentication, authorization, CSRF protection, project ownership checks, AI generation quotas and locks, secret handling, dependency vulnerabilities, and accidental exposure of private project data.

Novel Forge is an actively evolving hobbyist project. The public repository does not contain production secrets or database credentials. Deployments should provide secrets through the hosting platform's protected environment configuration rather than source files.
